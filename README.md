# AgriMandis Live
Run: `npm --prefix backend install && npm --prefix frontend install`, then `npm run dev:api` (port 4000) and `npm run dev:web` (port 5173). Tests: `npm test`.
Demo logins: farmer@agrimandis.in / farmer123, admin@agrimandis.in / admin123. Set JWT_SECRET in production.
Try the search: "Tomato in Dharwad". `sample_prices.csv` exercises missing price, wrong unit and unknown crop handling.
